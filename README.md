# HertzEvaluator

独立评测器，管理可审核用例、晋升与实验对比，作为快照采纳前的回归门。

An independent evaluator that manages reviewable cases, promotion, and experiment comparison, as the regression gate before a snapshot is adopted.

HertzEvaluator does not:

- train models;
- certify knowledge; or
- automatically push changes into production.
